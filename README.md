# trmnl-http-pets-plugin

Because a 502 Bad Gateway hurts slightly less when it's delivered by a confused duck.

Install it [here](https://trmnl.com/recipes/323180)!
## Requirements

- A TRMNL capable device!

## Local development

Run the template through the TRMNL's Web UI for testing.
